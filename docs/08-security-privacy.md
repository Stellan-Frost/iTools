# 08 · 安全与隐私

> 状态：**部分实现**。已遵守：无遥测/上传、本地处理边界、日志不记录用户内容；未实现：CSP、安全响应头、认证、API 限流、依赖扫描与 CI。当前静态资源全部同源本地托管。

## 数据边界
- 用户源文件、处理结果和普通用户任务数据只在浏览器本地处理/保存；禁止未经授权的遥测、分析或错误报告外传。
- 可请求必要的公开数据（例如汇率），但必须按来源审核并受 CSP 白名单控制；汇率工具专属行为在工具专项访谈决定。
- 后端只记录必要运行状态、路由、响应状态、耗时和错误代码。
- 浏览器诊断信息默认保存在本地或当前会话。
- 禁止日志记录文件内容、处理结果、认证凭据和敏感请求参数。
- 结构化应用日志保留 30 天，按日期和容量轮转。

## 网络与源站
- Cloudflare/CDN 代理、WAF、HTTPS 与速率限制。
- 源站防火墙限制直接访问，验证无法绕过代理访问源站。
- Fastify 分路由限流；可信代理配置与客户端 IP 识别集中管理。
- 公开只读 API 采用输入校验、限流和适当缓存；管理写 API 必须会话认证、服务端授权、CSRF 与来源检查。

## CSP 与响应头
- 严格 CSP，默认拒绝；只允许同源与经审核的公开数据接口、Worker、WASM 所需能力。
- 新增外部资源必须提交用途、数据流和安全影响，经审核后才可加入白名单；优先本地托管。
- 禁止未经审核的外部脚本、遥测和数据外传。
- CSP 与关键安全响应头进入自动化测试；安全检查失败通常发警告，由负责人决定是否发布，但已明确的硬性门禁仍有效。

## 依赖
- 固定 `pnpm-lock.yaml`；CI 自动扫描漏洞。
- 严重且可利用漏洞阻止合并；例外需记录理由、责任人、修复期限和复审。
- 许可证纳入依赖清单与开源致谢。
- 不额外设置严格依赖准入流程；新增依赖仍须遵守既定锁文件和漏洞扫描流程。

## 登录限流
- 管理员登录使用固定速率限制；不实现渐进延迟或永久账户锁定。
- 不记录密码、会话 Cookie 或其他认证凭据。

## 安全门禁解释
- 一般安全检查失败：告警并由负责人判断。
- 严重且可利用的依赖漏洞：阻止合并（既定硬规则）。
- 生产安全配置、公网规则变更仍需用户事先批准。
