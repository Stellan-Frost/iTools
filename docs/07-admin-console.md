# 07 · 管理后台

> 状态：**仅界面预览（阶段 8 待实施）**。`/{locale}/admin` 可访问，但没有认证、写入、数据库或权限校验；所有开关只存在内存。
> 阶段 8 的三项决策已定：**不给后台开放分类与图标编辑**（D29）、**元数据版本保留最近 50 版**（D30）、**初始化令牌来自环境变量 + 网页初始化页**（D31）。

## 权限模型
- 首期唯一管理员；不开放注册，不建设普通用户账户系统。
- 管理后台优先开发。
- 普通用户免登录，任务、偏好和结果保存在浏览器。
- 未来若需求变化需支持多管理员，另行提交架构变更；当前不实现多管理员协作编辑功能。

## 首次初始化与认证
- 首次管理员通过专用初始化页面创建；**部署时把一次性令牌注入环境变量 `ADMIN_SETUP_TOKEN`**，页面提交令牌 + 设置口令。
- 令牌只与内存中的环境变量比对，**不落库、不写日志**；初始化成功后入口永久关闭（再访问返回 409）。
- 未设置 `ADMIN_SETUP_TOKEN` 时初始化入口视为不存在，不允许任何创建路径。
- 服务端会话 + 安全 Cookie：HttpOnly、Secure、适当 SameSite、CSRF 防护、会话轮换、过期和主动撤销。
- 会话存 PostgreSQL；空闲 7 天失效，绝对有效期 30 天。
- 管理员密码重置只能通过需要服务器管理权限的专用恢复命令；撤销所有旧会话并记录安全事件；不开放公网恢复 API。
- 登录使用固定速率限制；不实现渐进延迟或永久账户锁定。
- 所有权限检查在服务端执行。

## 管理功能
- 工具启用/停用（只能下架或恢复注册表默认，不能启用不存在的实现）。
- 排序调整。
- 编辑工具名称、简介与中英文 SEO 元数据。
- 查看必要的工具状态与诊断信息。
- 元数据历史预览与一键回滚。
- 存储/目录状态与必要运行状态查看。
- **不可编辑分类与图标**（D29）：分类与图标属于工具身份，只由代码注册表决定；后台改动会让 URL 规则（分类必须匹配）与 `check:tools` 失效。
- 所有变更先校验 Schema、在必要时使用事务，并记录最小化结构化应用日志。

## 元数据版本
- 仅对可编辑的展示元数据保存版本快照；不建立全站独立审计表。
- 回滚必须检查目标版本、当前版本与字段合法性，防止覆盖更新内容。
- **保留策略（D30）**：每个「工具 + 语言」保留最近 50 个版本，按数量清理；当前生效版本永不被清理。
- 版本清理由统一维护调度器执行。

## UI
- 使用全站设计系统；中英文完整。
- 后台写操作必须显示明确结果和失败原因；破坏性操作需确认。
