# 02 · 应用框架、路由、国际化与 SEO

## URL 规则
- 语言前缀：`/zh-CN/...` 与 `/en/...`。
- 工具路径：`/{locale}/{category}/{tool-id}`，例如 `/zh-CN/text/json-formatter`、`/en/image/image-compressor`。
- 分类：`audio`、`image`、`video`、`text`、`other`。
- 工具 ID 与路由稳定标识由代码注册表管理，不由后台任意创建。

## SSR 与可用性
- Fastify 托管 React SSR 与构建资源。
- 直接请求工具 URL 时，服务端先确认代码注册表存在该工具，再查询数据库启用状态；仅当实现存在且启用时返回应用页面，否则返回真实 HTTP 404。
- 客户端导航、全局搜索、首页模块、分类页、最近使用和 Sitemap 使用相同可用性规则。
- 目录状态允许 CDN 自然过期造成短暂滞后，但缓存不得绕过直达路由的服务端状态检查。
- 不存在的路由不能返回 HTTP 200 的伪 404。

## 国际化
- 使用 `i18next + react-i18next`。
- 命名空间至少分为 `common`、`navigation`、`admin`、`tools/<tool-id>`；翻译资源按需加载。
- UI 文案放在 i18next；数据库中的工具名称、简介和 SEO 文案由 `tool_localizations` 管理，不得重复维护同一字段。
- 构建/测试检查缺失翻译；中文和英文必需字段缺失时不得生成错误 SEO 内容。
- 切换语言时保留对应工具；无法映射时回到对应语言首页并明确处理。

## 首页、搜索与导航
- 首页首屏：全局搜索 + 核心分类；下方按真实数据展示常用工具、最近使用和最近任务。
- 全局命令面板支持点击、键盘快捷键、方向键、Enter；移动端有触控入口。
- 搜索只展示代码注册表中真实存在、数据库当前启用的工具。
- 最近任务：导航中打开轻量面板，提供查看全部入口；独立页面支持筛选、排序、批量操作和存储管理。

## SEO
- SSR 输出语言正确的 title、description、canonical/语言关联链接。
- Fastify 动态生成 `sitemap.xml`，只包含代码实现存在且数据库启用的公开页面，包含中英文 URL。
- `robots.txt` 指向 Sitemap 并统一管理爬取规则。
- Sitemap 和公开页面元数据变化无需重新构建前端。
