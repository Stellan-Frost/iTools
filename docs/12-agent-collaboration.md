# 12 · Agent 与 Subagent 协作

## 角色
- 根 Agent：GPT-6 Sol，推理强度 Medium；负责规划、派发、接口裁决、集成、验收、冲突解决和文档核验。
- 子 Agent：GPT-6 Luna，推理强度 Medium；负责独立任务实施、测试与对应文档更新。
- 根 Agent 不能把未确认的架构决策伪装成用户已批准。

## 分支与所有权
- 每个任务使用独立 Git 分支或 Worktree。
- 派发前定义文件所有权、依赖、接口、输入输出、验收标准和禁止修改范围。
- 不同 Agent 不得并行修改同一核心契约文件，除非根 Agent明确协调。
- 子 Agent 必须运行自己负责的测试，报告实际命令、结果、失败与未测内容。

## 派发模板
每个任务必须包含：
1. 目标与不做事项。
2. 允许修改的文件/目录。
3. 依赖模块与已冻结接口。
4. 具体实现要求。
5. 必须运行的测试。
6. 验收标准。
7. 风险、假设与待决问题。
8. 文档更新要求。

## 集成流程
1. 根 Agent 先合并接口/契约变更，再派发依赖任务。
2. 子 Agent 在独立分支/Worktree 完成实现、测试和文档。
3. 根 Agent 检查变更范围、接口兼容、重复逻辑、隐私网络边界和测试报告。
4. 冲突由根 Agent 统一解决；不得静默覆盖其他分支内容。
5. CI 全部硬性检查通过后才可合并。
6. 生产部署与敏感变更仍须用户批准。

## 自主权限
Agent 可自主规划、并行开发、测试、修复、文档更新和隔离环境集成。
不得未经批准执行：生产部署、生产数据库迁移、破坏性数据操作、公网安全配置变更。
